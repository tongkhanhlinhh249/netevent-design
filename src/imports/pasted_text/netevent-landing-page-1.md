Redesign the current NetEvent public event landing page.

Use Vietnamese for all UI copy, labels, buttons, section titles, helper text, status badges, and footer links.

Goal:
Adjust the current landing page layout to follow a Luma-like reading flow:
- Keep the left column as a supporting column only
- Move “Giới thiệu sự kiện” and “Địa điểm” fully into the right column
- Do NOT separate these sections into full-width blocks across the whole page
- The right column should become a continuous reading column from top to bottom

Design direction:
- Inspired by Luma event page structure
- Public-facing event page, not dashboard style
- Clean, premium, simple, highly readable
- Light gray background
- Rounded cards
- Subtle borders and shadows
- Clear vertical content flow
- Desktop first, responsive for mobile
- Font: Inter or Be Vietnam Pro
- Primary accent: #FF8644
- Max content width: 1120–1160px

==================================================
NEW DESKTOP LAYOUT STRUCTURE
==================================================

Use a 2-column desktop layout.

Left column width:
360–400px

Right column width:
620–700px

Column gap:
32px

Main rule:
The left column is static/supporting.
The right column is the main content flow.

==================================================
SECTION STYLE RULES
==================================================

For “Giới thiệu sự kiện” and “Địa điểm”:
- Do not wrap the whole screen width
- Do not create horizontal section bands spanning the page
- Keep them aligned to the right content column
- Use vertical spacing between blocks: 32–40px
- Use subtle divider lines if needed
- Keep text width readable
- Make the reading flow feel continuous like Luma

==================================================
VISUAL HIERARCHY
==================================================

Hierarchy in right column:
- Title strongest
- Registration card second strongest
- About event third
- Location fourth

Spacing suggestion:
- Title to subtitle: 12px
- Subtitle to event meta: 24px
- Meta to registration card: 24–32px
- Registration card to About event: 40px
- About event to Location: 40px

IMPORTANT UX RULES
==================================================

- Right column is the primary reading and conversion flow
- Left column is supporting content only
- About event and Location must live in the right column
- Avoid splitting content into wide horizontal sections
- Follow Luma’s logic: poster left, all main event content right
- Keep the page feeling focused, readable, and conversion-friendly
- Registration should stay visible high on the page
- About and Location should feel like natural continuation of the event content

A Luma-inspired NetEvent landing page where:
